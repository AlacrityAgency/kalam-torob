## 📖 معرفی پروژه و چرایی نام «کَلَم»

خرید حضوری در پاساژها و مجتمع‌های تجاری بزرگ (نظیر بازار چارسو، علاءالدین، پایتخت، لاله‌زار، شوش و بازار بزرگ) تجربه‌ای طاقت‌فرسا همراه با خستگی ناشی از پیمایش طبقات متوالی، تفاوت قیمت‌های سردرگم‌کننده و ریسک بسته بودن مغازه یا اتمام موجودی است.

نام **«کَلَم»** از استعاره **پوست‌کندن گام‌به‌گام لایه‌های خرید در بازار** الهام گرفته شده است:

```mermaid
graph TD
    A["لایه ۱: انتخاب پاساژ و هاب (راسته تجاری، بورس کالا و ترافیک)"] --> B["لایه ۲: نقشه طبقات و مسیر بهینه (پیمایش یک‌طرفه و پله‌برقی‌ها)"]
    B --> C["لایه ۳: استعلام واحد و پیشخوان (پلاک دقیق، تماس ۱۲ ثانیه‌ای و گارانتی)"]
    C --> D["لایه ۴: تحویل، تست اصالت و دکمه نجات (همتا، فاکتور معتبر و Fallback پنیک)"]
```

## 🔬 الگوریتم‌های ۷گانه کَلَم

کَلَم مجهز به ۷ الگوریتم اختصاصی برای پردازش فضای فیزیکی خرده‌فروشی است:

| # | نام الگوریتم | کد اختصاری | عملکرد کلیدی |
| :--- | :--- | :--- | :--- |
| **۱** | **In-Person Cart Routing Problem** | `IP-CRP` | مسیریاب سبد خرید چندقلمی در فضای سه‌بعدی پاساژها با قید صعود یک‌طرفه و حمل کالای سنگین در ایستگاه آخر. |
| **۲** | **Spatial & Asymmetric Complementarity** | `PACO` | پیشنهاد اقلام مکمل در همان طبقه با فیلتر خودکار برندهای رقیب و جانشین هم‌عرض. |
| **۳** | **Indoor Mall Wayfinding Parser** | `IMWP` | پارسر هوشمند آدرس‌های متنی سنتی بازار، استخراج طبقات منفی و تولید راهنمای کلامی سه‌مرحله‌ای. |
| **۴** | **BNPL & In-Person POS Matcher** | `CrediPay` | اعتبارسنجی پذیرنده‌های فیزیکی اسنپ‌پی، ترب‌پی، تارا و دیجی‌پی بر اساس پایانه پوز متصل. |
| **۵** | **Interactive Need Decoupling Protocol** | `INDP` | غربالگری نیازهای مبهم خریدار در کمتر از ۳ ثانیه با درخت تشخیصی دوراهی. |
| **۶** | **Stock Certainty & 12s Inquiry Dossier** | `SVDP` | تنزیل زمانی قیمت‌های ثبت‌شده و تولید اسکریپت صوتی ۱۲ ثانیه‌ای جهت برقراری تماس قبل از حرکت. |
| **۷** | **Triple-Fallback Resilient Architecture** | `TFRA` | دکمه نجات پنیک (Panic Button): یافتن کالای جایگزین در همان طبقه (زیر ۲۰ متر)، همان پاساژ یا راسته مجاور هنگام برخورد با مغازه بسته. |

## 🎨 طراحی رابط کاربری: هم‌خانواده با ترب

رابط کاربری کَلَم با زبان بصری ترب طراحی شده تا برای کاربر ترب آشنا باشد:

- **ظاهر سفید و تمیز:** پس‌زمینه سفید و خاکستری روشن (`#f5f5f5`)، خطوط مرزی ظریف (`#e5e5e5`) و رنگ قرمز برند (`#d73948`).
- **صفحه خانه مثل ترب:** لوگو و جعبه جستجوی بزرگ در مرکز صفحه، جستجوهای پرطرفدار و شبکه کالاها.
- **کارت کالا:** تصویر، عنوان دوخطی، «از … تومان» و «در N فروشگاه حضوری».
- **صفحه کالا:** لیست فروشگاه‌های حضوری با پاساژ، طبقه و واحد، تازگی قیمت، اقساط حضوری و دکمه‌های مسیر، استعلام و «بسته بود؟».
- **تایپوگرافی فارسی:** فونت وزیرمتن (Vazirmatn) که داخل پروژه قرار دارد و بدون اینترنت هم کار می‌کند.
- **واکنش‌گرا:** طراحی برای موبایل (۳۶۰ پیکسل) تا دسکتاپ، بدون اسکرول افقی.

## 🚀 راه‌اندازی سریع (Quick Start)

### پیش‌نیازها
- پایتون نسخه 3.9 به بالا

### ۱. کلون مخزن
```bash
git clone https://github.com/AlacrityAgency/kalam-torob.git
cd kalam-torob
```

### ۲. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۳. ساخت پایگاه داده
مسیر فایل zip دیتاست ترب را بدهید (CSVها خودکار در `dataset/` استخراج می‌شوند):
```bash
python scripts/build_db.py path/to/starcoach-dataset-v16-cap300-csv.zip
```
اگر CSVها از قبل در پوشه `dataset/` هستند، همان `python scripts/build_db.py` کافی است.

اگر دیتاست واقعی را ندارید، برای اجرای محلی یک دیتاست **نمونه و ساختگی** با همان ساختار بسازید (نام مغازه‌ها، قیمت‌ها و شماره‌ها واقعی نیستند):
```bash
python scripts/generate_sample_dataset.py
python scripts/build_db.py
```
*این اسکریپت جدول‌های نرمال‌شده `shops`, `products`, `offers` و جدول FTS5 جستجوی تمام‌متن فارسی را می‌سازد.*

### ۴. اجرای وب‌سرور
```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
👉 **`http://127.0.0.1:8000/`**

### اجرای یک‌مرحله‌ای در ویندوز
نصب وابستگی‌ها، ساخت پایگاه داده از zip، اجرای سرور و باز کردن مرورگر:
```bat
run_windows.bat "C:\Users\<you>\Downloads\starcoach-dataset-v16-cap300-csv.zip"
```
دفعه‌های بعد فقط `run_windows.bat` (بدون مسیر zip). اگر سرور در حال اجراست، قبل از ساخت دوباره پایگاه داده آن را ببندید.

### دیپلوی با Docker و لیارا
پروژه `Dockerfile`، `liara.json` و `docker-compose.yml` دارد. پایگاه داده روی دیسک دائمی `/data` ساخته می‌شود تا با هر دیپلوی دوباره ساخته نشود.

```bash
# اجرای محلی با Docker (zip دیتاست را با نام dataset.zip کنار پروژه بگذارید)
docker compose up --build
```

روی لیارا:
1. یک دیسک با نام `kalam-data` بسازید (در `liara.json` به `/data` وصل می‌شود).
2. یکی از این دو را تنظیم کنید تا داده واقعی بارگذاری شود:
   - `DATASET_ZIP_PATH=/data/dataset.zip` و فایل zip را روی همان دیسک بگذارید، یا
   - `DATASET_ZIP_URL` = لینک دانلود مستقیم zip دیتاست.
3. `liara deploy`

**دیپلوی خودکار:** در تنظیمات مخزن GitHub، secret به نام `LIARA_API_TOKEN` و متغیر `LIARA_APP` (نام برنامه در لیارا) را بگذارید؛ از آن به بعد هر push به main پس از سبز شدن تست‌ها خودکار دیپلوی می‌شود.

اگر هیچ‌کدام تنظیم نشود، برنامه با داده نمونه بالا می‌آید و رابط کاربری بنر «داده نمونه و ساختگی» نشان می‌دهد. برای ساخت دوباره پایگاه داده `KALAM_REBUILD_DB=1` بگذارید.

متغیرهای اختیاری: `ANTHROPIC_API_KEY` (درک پیام با Claude؛ بدون آن پارسر محلی فارسی کار می‌کند)، `KALAM_LLM_MODEL`، `WEB_CONCURRENCY`.

### ۵. اجرای تست‌ها
```bash
python -m unittest discover -s tests
```

## 🧠 قابلیت‌های دستیار

- **یک جمله، همه شرایط:** «گوشی A55 قسطی در چارسو تا ۲۵ میلیون» → کالا، محدوده، بودجه و اقساط هم‌زمان اعمال می‌شوند.
- **حافظه گفتگو:** «ارزون‌ترش کدومه؟»، «تا ۲۰ میلیون چی؟» و «قسطی هم داره؟» روی همان جستجوی قبلی اعمال می‌شوند.
- **درخت نیاز مبهم دومرحله‌ای:** کاربرد، سپس بودجه؛ بدون حلقه تکرار.
- **ساعت کاری واقعی:** «الان باز است تا ۲۰:۰۰»، «جمعه‌ها تعطیل»، و «ساعت کاری ثبت نشده» برای فروشگاه‌هایی که داده ندارند.
- **شفافیت داده:** آفرهای کپی و قیمت‌های پرت از کمترین قیمت حذف و برچسب‌گذاری می‌شوند؛ فروشگاه‌های فقط‌دسته‌فعالیت جدا نمایش داده می‌شوند؛ نشان اینستاگرام/وب‌سایت برای فروشگاه‌های دارای هویت آنلاین واقعی.
- **ایجنت داخل دستیار (🤖):** دستیار یکی است و خودش تشخیص می‌دهد: سؤال («A55 قسطی در چارسو») جواب گفتگو می‌گیرد و کار («... پیدا کن و هماهنگ کن» یا «هماهنگ کن» بعد از یک جستجو) را ایجنت همان‌جا در گفتگو اجرا می‌کند: فهم درخواست، پیدا کردن کالا، مقایسه فروشگاه‌ها، پیگیری به ترتیب (اگر یکی بسته بود سراغ بعدی)، برنامه مراجعه و اقلام مکمل همان مغازه؛ هر قدم زنده و با دلیل. دکمه «🤖 هماهنگ کن» روی کارت‌های چت، «ایجنت: برام هماهنگ کن» در صفحه کالا و «پیگیری با فروشنده» در صفحه کالا و مسیر سبد هم همگی داخل همین دستیار اجرا می‌شوند.
- **دستیار کنار صفحه:** در صفحه‌های عریض دستیار کنار صفحه ثابت می‌شود و صفحه کنارش جا باز می‌کند؛ با یک دکمه شناور هم می‌شود.
- **نقشه:** فروشگاه‌های هر کالا (پیشنهاد کلم، باز، بسته، نامشخص)، مسیر سبد خرید با شماره توقف‌ها، مراکز خرید در صفحه اول و نتیجه مأموریت ایجنت، همراه موقعیت کاربر. Leaflet داخل پروژه است و بدون اینترنت هم نشانگرها نمایش داده می‌شوند.
- **موقعیت و فاصله:** موقعیت از GPS مرورگر یا انتخاب محدوده؛ مرتب‌سازی «نزدیک‌ترین»، فیلتر «فاصله از شما» و لینک مسیریابی نقشه.
- **پیشنهاد کلم با دلیل:** در صفحه کالا یک فروشگاه بر اساس قیمت، فاصله، باز بودن و تازگی قیمت پیشنهاد می‌شود، همراه دلیل‌ها و هشدارها.
- **مقایسه کالاها:** تا ۴ کالا کنار هم (قیمت، تعداد فروشگاه، فاصله، اقساط، مشخصات فنی).
- **ایجنت پیگیری:** ساعت کاری ← پاسخ‌گویی ← قیمت و موجودی ← گارانتی ← اقساط، و تصمیم «بروید / اول تماس بگیرید / به جایگزین بروید».
- **بهترین زمان مراجعه:** برای مسیر سبد، زمانی که همه مغازه‌های مسیر باز هستند؛ در چت با «کی برم؟».
- **PWA و آفلاین:** نصب روی موبایل و باز شدن صفحه‌های دیده‌شده بدون اینترنت.
- **شبیه‌ساز استعلام:** پرسش موجودی، گارانتی، اقساط، ساعت کاری و رزرو از فروشنده، با پاسخ‌هایی که فقط از داده همان آفر ساخته می‌شوند و برچسب «شبیه‌سازی» دارند.

```text
kalam-torob/
├── backend/
│   ├── algorithms/          # پیاده‌سازی الگوریتم‌های ۷گانه
```
