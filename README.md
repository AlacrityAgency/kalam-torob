## 📖 معرفی پروژه و چرایی نام «کَلَم»

خرید حضوری در پاساژها و مجتمع‌های تجاری بزرگ (نظیر بازار چارسو، علاءالدین، پایتخت، لاله‌زار، شوش و بازار بزرگ) تجربه‌ای طاقت‌فرسا همراه با خستگی ناشی از پیمایش طبقات متوالی، تفاوت قیمت‌های سردرگم‌کننده و ریسک بسته بودن مغازه یا اتمام موجودی است.

نام **«کَلَم»** از استعاره **پوست‌کندن گام‌به‌گام لایه‌های خرید در بازار** الهام گرفته شده است:

```mermaid
graph TD
    A["لایه ۱: انتخاب پاساژ و هاب (راسته تجاری، بورس کالا و ترافیک)"] --> B["لایه ۲: نقشه طبقات و مسیر بهینه (پیمایش یک‌طرفه و پله‌برقی‌ها)"]
    B --> C["لایه ۳: استعلام واحد و پیشخوان (پلاک دقیق، تماس ۱۲ ثانیه‌ای و گارانتی)"]
    C --> D["لایه ۴: تحویل، تست اصالت و دکمه نجات (همتا، فاکتور معتبر و Fallback پنیک)"]
```

## 🔬 الگوریتم‌های ۷گانه کَلَم

کَلَم مجهز به ۷ الگوریتم اختصاصی برای پردازش فضای فیزیکی خرده‌فروشی است:

| # | نام الگوریتم | کد اختصاری | عملکرد کلیدی |
| :--- | :--- | :--- | :--- |
| **۱** | **In-Person Cart Routing Problem** | `IP-CRP` | مسیریاب سبد خرید چندقلمی در فضای سه‌بعدی پاساژها با قید صعود یک‌طرفه و حمل کالای سنگین در ایستگاه آخر. |
| **۲** | **Spatial & Asymmetric Complementarity** | `PACO` | پیشنهاد اقلام مکمل در همان طبقه با فیلتر خودکار برندهای رقیب و جانشین هم‌عرض. |
| **۳** | **Indoor Mall Wayfinding Parser** | `IMWP` | پارسر هوشمند آدرس‌های متنی سنتی بازار، استخراج طبقات منفی و تولید راهنمای کلامی سه‌مرحله‌ای. |
| **۴** | **BNPL & In-Person POS Matcher** | `CrediPay` | اعتبارسنجی پذیرنده‌های فیزیکی اسنپ‌پی، ترب‌پی، تارا و دیجی‌پی بر اساس پایانه پوز متصل. |
| **۵** | **Interactive Need Decoupling Protocol** | `INDP` | غربالگری نیازهای مبهم خریدار در کمتر از ۳ ثانیه با درخت تشخیصی دوراهی. |
| **۶** | **Stock Certainty & 12s Inquiry Dossier** | `SVDP` | تنزیل زمانی قیمت‌های ثبت‌شده و تولید اسکریپت صوتی ۱۲ ثانیه‌ای جهت برقراری تماس قبل از حرکت. |
| **۷** | **Triple-Fallback Resilient Architecture** | `TFRA` | دکمه نجات پنیک (Panic Button): یافتن کالای جایگزین در همان طبقه (زیر ۲۰ متر)، همان پاساژ یا راسته مجاور هنگام برخورد با مغازه بسته. |

## 🎨 طراحی رابط کاربری: هم‌خانواده با ترب

رابط کاربری کَلَم با زبان بصری ترب طراحی شده تا برای کاربر ترب آشنا باشد:

- **ظاهر سفید و تمیز:** پس‌زمینه سفید و خاکستری روشن (`#f5f5f5`)، خطوط مرزی ظریف (`#e5e5e5`) و رنگ قرمز برند (`#d73948`).
- **صفحه خانه مثل ترب:** لوگو و جعبه جستجوی بزرگ در مرکز صفحه، جستجوهای پرطرفدار و شبکه کالاها.
- **کارت کالا:** تصویر، عنوان دوخطی، «از … تومان» و «در N فروشگاه حضوری».
- **صفحه کالا:** لیست فروشگاه‌های حضوری با پاساژ، طبقه و واحد، تازگی قیمت، اقساط حضوری و دکمه‌های مسیر، استعلام و «بسته بود؟».
- **تایپوگرافی فارسی:** فونت وزیرمتن (Vazirmatn) که داخل پروژه قرار دارد و بدون اینترنت هم کار می‌کند.
- **واکنش‌گرا:** طراحی برای موبایل (۳۶۰ پیکسل) تا دسکتاپ، بدون اسکرول افقی.

## 🚀 راه‌اندازی سریع (Quick Start)

### پیش‌نیازها
- پایتون نسخه 3.9 به بالا

### ۱. کلون مخزن
```bash
git clone https://github.com/AlacrityAgency/kalam-torob.git
cd kalam-torob
```

### ۲. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۳. ساخت پایگاه داده
مسیر فایل zip دیتاست ترب را بدهید (CSVها خودکار در `dataset/` استخراج می‌شوند):
```bash
python scripts/build_db.py path/to/starcoach-dataset-v16-cap300-csv.zip
```
اگر CSVها از قبل در پوشه `dataset/` هستند، همان `python scripts/build_db.py` کافی است.

اگر دیتاست واقعی را ندارید، برای اجرای محلی یک دیتاست **نمونه و ساختگی** با همان ساختار بسازید (نام مغازه‌ها، قیمت‌ها و شماره‌ها واقعی نیستند):
```bash
python scripts/generate_sample_dataset.py
python scripts/build_db.py
```
*این اسکریپت جدول‌های نرمال‌شده `shops`, `products`, `offers` و جدول FTS5 جستجوی تمام‌متن فارسی را می‌سازد.*

### ۴. اجرای وب‌سرور
```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
👉 **`http://127.0.0.1:8000/`**

### اجرای یک‌مرحله‌ای در ویندوز
نصب وابستگی‌ها، ساخت پایگاه داده از zip، اجرای سرور و باز کردن مرورگر:
```bat
run_windows.bat "C:\Users\<you>\Downloads\starcoach-dataset-v16-cap300-csv.zip"
```
دفعه‌های بعد فقط `run_windows.bat` (بدون مسیر zip). اگر سرور در حال اجراست، قبل از ساخت دوباره پایگاه داده آن را ببندید.

### ۵. اجرای تست‌ها
```bash
python -m unittest discover -s tests
```
